# Expense Management Dashboard

Angular standalone application starter using PrimeNG, RxJS, Reactive Forms, Angular Router, mock data, and localStorage.

## Install dependencies
Run inside your existing Angular project:
```bash
npm install primeng @primeuix/themes primeicons chart.js
```

Replace the matching files in `src/` with the files in this archive. Keep your existing `package.json`, `angular.json`, and `tsconfig` files.

If your existing project uses a different PrimeNG major version, some PrimeNG component names may need small adjustments.

## Run
```bash
ng serve
```

The app stores expense records in localStorage. Use Settings > Reset demo data to restore sample data.
